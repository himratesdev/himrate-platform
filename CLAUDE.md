## ⚡ ГОНКИ СЕССИЙ — ЖЕЛЕЗНЫЕ ПРАВИЛА

В этом клоне параллельно работают НЕСКОЛЬКО Claude-сессий («ферма» + основная). Рабочее дерево
ОДНО. Два реальных инцидента (2026-09-02 и 2026-09-05): чужой checkout склоббил незакоммиченные
правки соседа, и половина фикса уехала в чужой коммит.

1. **Длинная задача (>1 файла или >10 минут) → СВОЙ git worktree**:
   `git worktree add ../himrate-platform-<задача> -b <ветка>` — и работай ТОЛЬКО там.
2. **Быстрая правка в общем клоне → коммит СРАЗУ после каждого логического шага.**
   Незакоммиченный файл в общем дереве живёт до первого чужого checkout.
3. **НЕ делай `git add -A` / `commit -am` в общем клоне** — заберёшь чужие незакоммиченные файлы
   (прецедент: чужой methodology.html.erb уехал в коммит W1). Добавляй файлы поимённо.
4. **Пуш в `home` после завершения задачи** (`git push home <ветка>`) — bare-репо на сервере =
   единственный бэкапируемый источник; локальный клон не считается сохранённым.
5. `git checkout -- .` / `reset --hard` / `clean` в общем клоне — только убедившись через
   `git status`, что затираешь СВОЁ.
